# Contributing

Read the [developer guide](docs/manuals/Developer-Manual.md) before changing code.

Keep each change small. Explain the problem, the change and the checks you actually ran. List skipped or unavailable checks separately. Preserve unrelated local work, runtime verification, memory checks and model files.

Do not commit model weights, build output, credentials, private paths or signing keys. Follow the existing experiment structure and do not regenerate evidence for unrelated changes.

The project owner has not supplied a root project licence here. Ask the owner to confirm contribution and distribution terms before submitting work for redistribution. Third-party notices remain separate; see [licence status](docs/manuals/Licence-Status.md).
