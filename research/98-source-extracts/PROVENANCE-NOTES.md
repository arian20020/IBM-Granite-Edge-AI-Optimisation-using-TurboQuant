# Provenance notes for preserved extracts

The files below this directory are lossless transformations of the supplied DOCX research. They may contain:

- bare filenames such as `2504.19874v1.pdf`;
- old or duplicated URLs;
- author-reported repository results;
- a private SharePoint link;
- earlier interpretations that were later refined.

They are intentionally **not edited**, because changing them would weaken the audit trail. Use the curated notes and `00-sources` for current citations.

## Private link rule

The private SharePoint link remains in the extract only as historical evidence. It is catalogued as `SRC-PRIVATE-SHAREPOINT-RETIRED` and must not be cited as a publicly reproducible source.
