# TurboQuant and llama.cpp repository reviews

These files retain the detailed notes from the supplied repository research. Each review should be read as an engineering assessment, not an endorsement.

Start with [`comparison-matrix.md`](comparison-matrix.md), then read the detailed repository file before testing any fork. Use [`review-template.md`](review-template.md) and the common sequence in [`../07-evaluation-and-decisions/01-common-test-sequence.md`](../07-evaluation-and-decisions/01-common-test-sequence.md).

Every review asks the same questions: what is implemented, where it is integrated, what hardware it assumes, whether Granite is supported, what evidence exists and what must be reproduced locally.
