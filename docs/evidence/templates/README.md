# Evidence Template Guidance

Use the [Evidence Record Template](Evidence-Record-Template.md) for requirement, work-package and engineering-practice evidence packs.

## How to use it

1. Copy the template into the required evidence folder as `README.md`.
2. Replace every placeholder with project-specific information.
3. Link to the authoritative document, code, test, experiment, log, screenshot, manifest, checksum, commit or pull request.
4. Do not copy the same authoritative artefact into several evidence folders.
5. Complete each validation check before setting the record to `Validated` or `Verified`.
6. Record unresolved gaps honestly as limitations, blockers or follow-up work.

## Status rule

- **Implemented** means the deliverable exists.
- **Validated** means the stated Definition of Done or acceptance criteria were checked against evidence.
- **Verified** is used only when implementation and validation are both complete.

A folder containing only an empty or generic README is not completion evidence.
