# Report source fragments

The full report source is kept outside this repository. This directory stores small, controlled sections that must stay aligned with repository evidence.

- [`Risk-Assumption-Licence-Registers.tex`](appendices/Risk-Assumption-Licence-Registers.tex) contains the report appendix for the main risks, selected assumptions and dependency licences.

Copy or include the fragment in the full report. Check it again after a risk, assumption or licence decision changes.

- [Manuals-and-Handover.tex](appendices/Manuals-and-Handover.tex) contains three separately marked bodies without chapter commands. Copy each body below its matching existing chapter heading and label, replacing only that chapter's old body. Do not include the whole file in one place. Keep unrelated appendices unchanged. Recompile the report and check its contents page and references. This update does not edit the external full report.
