# Traceability Data

This directory contains the machine-readable repository snapshot generated from the controlled RTM workbook.

| File | Purpose |
|---|---|
| `task-catalogue.json` | Complete normalized snapshot of active tasks, objectives, RQs and all requirement lifecycle records. |
| `task-catalogue.schema.json` | Structural contract for the catalogue format. |
| `source-metadata.json` | Small provenance record containing version, date, checksum and counts. |

`task-catalogue.json` and `source-metadata.json` are generated files. Do not edit them manually.
