# Traceability Baselines

This directory records the provenance of each RTM snapshot used to generate repository traceability files.

A source record should include:

- logical RTM version;
- original filename;
- SHA-256 checksum;
- generation date;
- sheet names used;
- expected record counts;
- repository branch or pull request containing the generated snapshot;
- known limitations or later replacement version.
