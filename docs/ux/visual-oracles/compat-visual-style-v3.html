Budget & candidates

Budget split into weights / KV / buffers / headroom / reserve, then the candidate set in the approved .check-list grammar. Strongest on screens 04 and 05 where a trade-off must be made, and it makes the four optimisation modes tangible. Denser, and it surfaces uncalibrated component figures on the main card rather than behind the disclosure.

Geometry rules now enforced

Every grid and flex child can shrink (min-width:0), so no pill, label or value can push outside its card. Cards clip their own content (overflow:hidden). Columns stretch to equal height and the side stack uses equal rows, so left and right finish level. Fact tiles share one row height with the detail line pinned to the bottom, giving a straight horizontal line across the grid. Budget segments are grid tracks that clip their own labels. One --gap token drives every vertical space, so the rhythm is identical on all three.

Recommendation unchanged

A as the base for all ten screens, borrowing C’s candidate list only on screens 04 and 05.
