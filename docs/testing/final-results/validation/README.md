# Validation receipts

These receipts record the ordered collection validation gates and the release-specific PDF, workbook, archive, and metadata checks. Validation itself is read-only; receipt publication is an explicit separate step performed only after the published path set is settled.

The cleanup-finalization result is available as the machine-readable
[`validation.json`](validation.json) receipt and the matching human-readable
[`validation.md`](validation.md) summary. Release-level QA details remain in
[`release-readiness.json`](release-readiness.json).
