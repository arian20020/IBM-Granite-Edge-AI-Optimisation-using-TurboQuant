# OpenVINO Codec Register Integration

The revision 1.1 delivery package contains the fully merged machine-readable registers for the expanded OpenVINO campaign. The Git branch keeps the 119 new IDs in `OpenVINO-Codec-Traceability-Extension-v1.1.csv` so the extension is reviewable without rewriting historical source-audit rows.

Before execution, extract the revision 1.1 package over the cloned repository or merge the extension rows into the main registers. The controlling generated package includes:

- 224 test-traceability rows;
- 285 workbook-completion rows;
- 50 build/setup rows;
- 156 planned configurations;
- 156 device-verification rows;
- 180 performance-measurement rows;
- 210 quality-evaluation rows;
- 26 cross-route comparison rows.

No row is a test result. All active result fields remain blank until evidence is captured on the target Windows Intel machine.
