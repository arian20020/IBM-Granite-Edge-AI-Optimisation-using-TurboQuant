# Previous Testing Campaign Status

**Classification:** Legacy / superseded for final conclusions  
**Retention rule:** Do not delete recoverable evidence.

The previous testing work remains useful as historical and diagnostic material, but it is not automatically authoritative because the full chain from environment and command to raw evidence, workbook entry and conclusion was not consistently available in GitHub.

Legacy evidence may be reused only when:

1. the exact test and run can be identified;
2. the environment, repository commit, model and command can be reconstructed;
3. the raw evidence is intact;
4. the result can be independently checked;
5. the decision to reuse it is recorded in `Decision-Log.md`.

Otherwise, the test must be repeated within the controlled campaign.
