# Model Import Drop Card Refinement

Restore the rounded dashed-border import card. Keep its geometry stable across all states. When a single supported item is dragged over it, use a blue-tinted background, stronger blue dashed outline, target/download icon, and the text "Drop model now". Invalid or multi-item drops use a red-tinted outlined state and clear corrective text. Leaving the region restores the default state. The visual state must be accessible, use existing theme resources, and avoid motion/layout shifts.
