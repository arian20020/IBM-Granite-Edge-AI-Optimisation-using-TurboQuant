**Goal:** Close H1's R3 native-dependency phase and make every H1 verification claim reproducible from committed privacy-safe result ledgers.

- [ ] **Step 4: Implement strict Python parsing and stable failures**

Implement `load_bounded_json` with a literal 1 MiB maximum and duplicate-key hook:

```python
MAX_JSON_BYTES = 1024 * 1024

class ClosureFailure(Exception):
    def __init__(self, code: str):
        super().__init__(code)
        self.code = code

def reject_duplicate_pairs(pairs):
    result = {}
    for key, value in pairs:
        if key in result:
            raise ClosureFailure("H1R3-JSON-DUPLICATE")
        result[key] = value
    return result

def load_bounded_json(path):
    data = pathlib.Path(path).read_bytes()
    if not data or len(data) > MAX_JSON_BYTES:
        raise ClosureFailure("H1R3-JSON-BOUNDS")
    try:
        return json.loads(data.decode("utf-8", "strict"), object_pairs_hook=reject_duplicate_pairs)
    except ClosureFailure:
        raise
    except (UnicodeDecodeError, json.JSONDecodeError):
        raise ClosureFailure("H1R3-JSON-INVALID")
```
