# IBM Granite Edge AI Optimisation using TurboQuant

WinUI 3 desktop research prototype for importing, inspecting, configuring and running selected IBM Granite models locally on Windows 11 Intel computers. The project also evaluates standard and TurboQuant-enabled inference routes, memory/quality trade-offs and a bounded TurboVec-assisted knowledge-file workflow using controlled evidence.

## Important boundary

This repository contains a research prototype. It is not a clinical system, is not approved for real patient or pupil data, and is not a replacement for professional judgement.

## Evidence rule

Measured results, estimates, published claims and experimental findings are kept separate. Large model weights, third-party builds and secrets are not committed; their revisions, licences and hashes are recorded instead. A task becomes Verified only after its implementation and stated acceptance evidence are both validated in the controlled RTM.
