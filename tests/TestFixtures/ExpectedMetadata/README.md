# Expected Metadata

This directory contains expected metadata for representative valid GGUF
fixtures.

Expected-result files should use the same identifier as their corresponding
GGUF fixture.

`Generate-GgufMetadataFixtures.ps1` writes these records from explicit expected
values. Each record includes the stable fixture ID, fixture filename, every
observable successful scan field, exact generated byte length, and SHA-256
hash. Tests must assert both `fixtureId` and `fixtureFile` before comparing the
public scanner result.

The expectation values are independent of the production scanner. Regeneration
never obtains expected metadata by scanning the generated binary.

The current set contains one expectation for each V-001 through V-012 valid
metadata fixture. V-009 proves all official metadata types and nested arrays
can coexist with extracted Granite fields; V-010 documents the stable
`Unknown (file type 999)` label.
