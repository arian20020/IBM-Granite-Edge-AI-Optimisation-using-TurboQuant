# Getting help

For a normal bug, open an issue in this repository's Issues tab. If issues are unavailable, use the project contact through which you received the app. No dedicated support email or response time is promised here.

Include:

- Package filename and version, if known. Say if you do not know.
- Windows version, model name, GGUF or OpenVINO route, and the step that failed.
- The visible message and diagnostic code.
- Short steps to repeat the problem and whether it happens after reopening.
- A cropped screenshot with private information removed.

Do not upload private prompts, model weights, your whole data folder or unedited logs. If logs are needed, ask which file and lines are relevant, make a copy and remove private information before sharing it. There is no single verified log location documented for every route.

For security concerns, follow [SECURITY.md](SECURITY.md). For common problems, read [troubleshooting](docs/manuals/Known-Limitations.md#troubleshooting).
